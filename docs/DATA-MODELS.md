# Data models

Reference for every table, field and attribute. **Nothing here is applied yet** except what the migration history shows (currently no migrations). Tables are added **per feature**, one Prisma migration each, in the order of the day plan. The Prisma sketch at the end is the target; adjust it when implementing and keep this file in sync.

## Conventions
- **IDs:** `String @id @default(cuid())` (proposed; confirm before the first migration).
- **Timestamps:** `createdAt DateTime @default(now())`, `updatedAt DateTime @updatedAt` on every table unless noted.
- **Naming:** models singular PascalCase, fields camelCase. Prisma default table names (no `@@map`) unless there is a reason.
- **Visibility:** every content table has `isPublished Boolean @default(false)`. The public API returns only `isPublished = true` rows. Tags and Profile have no `isPublished`.
- **Ordering:** `sortOrder Int @default(0)` where the owner arranges items by hand (lower comes first), otherwise order by date.
- **Markdown:** `content`/`description` fields hold markdown text, use `@db.Text`.
- **Files:** only URLs are stored (strings). Files live in the Neon bucket `portfolio-media`; keys are generated server-side, for example `articles/<uuid>.webp`.
- **Slugs:** lowercase, hyphenated, derived from the title with a shared util, unique per table.
- **Single owner:** no `userId` on content tables. There is exactly one admin account.

## Better Auth tables (Day 1)
Generated by the Better Auth CLI into `schema.prisma` (do not hand-write; re-generate after adding plugins). Standard shape for reference, verify against the generated output:

| Model | Fields (typical) |
|---|---|
| **User** | `id`, `name`, `email` (unique), `emailVerified Boolean`, `image String?`, `createdAt`, `updatedAt` |
| **Session** | `id`, `token` (unique), `expiresAt`, `ipAddress String?`, `userAgent String?`, `userId` → User, `createdAt`, `updatedAt` |
| **Account** | `id`, `accountId`, `providerId`, `userId` → User, `password String?` (hashed), token fields, `createdAt`, `updatedAt` |
| **Verification** | `id`, `identifier`, `value`, `expiresAt`, `createdAt`, `updatedAt` |

Notes: sign-up is **disabled**; the single admin is created by a seed script. No `role` field is needed (one user).

## Tag
Technology or topic with a logo. Shared by Articles and Projects.

| Field | Type | Attributes | Notes |
|---|---|---|---|
| id | String | `@id @default(cuid())` | |
| name | String | required | Display name, e.g. `TypeScript` |
| slug | String | `@unique` | e.g. `typescript` |
| iconSlug | String? | | [Simple Icons](https://simpleicons.org) slug, e.g. `react`, `typescript`, `claude` |
| iconUrl | String? | | Uploaded SVG/PNG URL, used when Simple Icons has no logo |
| color | String? | | Brand hex color, e.g. `#3178C6` |
| createdAt / updatedAt | DateTime | | |
| articles | Article[] | implicit m:n | |
| projects | Project[] | implicit m:n | |

Rules: at most one of `iconSlug` / `iconUrl` is needed; the frontend prefers `iconUrl` if both exist. No `isPublished`: tags appear through the published items that use them.
Public: `GET /public/tags`, `GET /public/tags/:slug` (the tag plus its published articles and projects).

## Relationships
```
Tag ⟷ Article   (many-to-many, implicit)
Tag ⟷ Project   (many-to-many, implicit)
Better Auth: User 1─* Session, User 1─* Account
(all other models are standalone)
```

## Reference Prisma sketch (target, not yet applied)
```prisma
enum CareerType {
  WORK
  EDUCATION
}

model Tag {
  id        String    @id @default(cuid())
  name      String
  slug      String    @unique
  iconSlug  String?
  iconUrl   String?
  color     String?
  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt
  articles  Article[]
  projects  Project[]
}

model Article {
  id            String    @id @default(cuid())
  title         String
  slug          String    @unique
  excerpt       String
  content       String    @db.Text
  coverImageUrl String?
  isPublished   Boolean   @default(false)
  publishedAt   DateTime?
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt
  tags          Tag[]

  @@index([isPublished, publishedAt])
}

model Certificate {
  id            String   @id @default(cuid())
  title         String
  issuer        String
  issueDate     DateTime
  credentialUrl String?
  fileUrl       String?
  imageUrl      String?
  isPublished   Boolean  @default(false)
  sortOrder     Int      @default(0)
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt
}

model Project {
  id            String   @id @default(cuid())
  title         String
  slug          String   @unique
  summary       String
  content       String   @db.Text
  repoUrl       String?
  liveUrl       String?
  coverImageUrl String?
  isPublished   Boolean  @default(false)
  sortOrder     Int      @default(0)
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt
  tags          Tag[]
}

model Service {
  id          String   @id @default(cuid())
  title       String
  description String
  features    String[]
  iconSlug    String?
  iconUrl     String?
  isPublished Boolean  @default(false)
  sortOrder   Int      @default(0)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}

model CareerEntry {
  id           String     @id @default(cuid())
  type         CareerType
  role         String
  organization String
  location     String?
  startDate    DateTime
  endDate      DateTime?
  description  String     @db.Text
  isPublished  Boolean    @default(false)
  sortOrder    Int        @default(0)
  createdAt    DateTime   @default(now())
  updatedAt    DateTime   @updatedAt
}

model Profile {
  id          String   @id
  name        String
  headline    String
  bio         String   @db.Text
  avatarUrl   String?
  resumeUrl   String?
  location    String?
  publicEmail String?
  socialLinks Json     @default("[]")
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}

model ContactMessage {
  id        String   @id @default(cuid())
  name      String
  email     String
  message   String   @db.Text
  isRead    Boolean  @default(false)
  createdAt DateTime @default(now())
}
```
Prisma 7 notes: the datasource block has no `url` (it lives in `prisma7.config.ts`); generator is `prisma-client` with output `../src/generated/prisma`. Better Auth models are added by its CLI, not written here.
